# Liza в Zed

Расширение добавляет подсветку синтаксиса `.liza`, парные скобки, отступы,
комментирование строк и список функций, структур и вариантов `enum` в Outline.
Поддерживаются конструкции ядра 0.0.16, включая `copy`/`move`, readonly views,
`Option`/`Result`, эффекты и checked/wrapping/saturating-операторы.
Цвета берутся из выбранной темы Zed.

## Установка

1. Обновите локальный репозиторий Liza: `git pull`.
2. В Zed откройте палитру команд: `Cmd+Shift+P` на macOS или `Ctrl+Shift+P` на Linux/Windows.
3. Выполните **`zed: install dev extension`**.
4. Выберите каталог **`editors/zed`** внутри репозитория Liza.
5. Откройте `examples/hello.liza` или `examples/connection_table.liza`.
   В строке состояния должен появиться язык **Liza**.

Это локальная установка: расширение пока не опубликовано в каталоге Zed.
При первой установке нужен интернет для загрузки закреплённой версии грамматики
и инструментов её сборки. Zed автоматически скачивает WASI SDK.
Процедура описана в [документации Zed](https://zed.dev/docs/extensions/developing-extensions).
При ошибке откройте `zed: open log`; после обновления расширения повторите установку.

## Что входит в первую версию

- Ключевые слова, целочисленные типы, числа, строки UTF-8, escape-последовательности и комментарии.
- Имена функций, параметров и полей, конструкторы и варианты.
- Операторы, включая `+%`, `+|`, сдвиги и диапазоны views.
- Outline для `fn`, `struct` и `enum`; парные скобки и базовые отступы.

Подсветка синтаксическая. Имена конструкторов распознаются по соглашению
об именовании с заглавной буквы. Грамматика редактора допускает незавершённый
код и более свободные пробелы/переносы; она не заменяет проверки компилятора.
LSP, автодополнение, переход к определению и диагностика типов пока не входят
в расширение. Проверяйте программу командой:

```sh
python3 -m liza check examples/hello.liza
```
