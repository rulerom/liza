# UDP: первый срез

`net.DatagramSocket` — move-only ресурс. `net.udp_bind(net.Address)` открывает
блокирующий IPv4 UDP-сокет; `net.udp_port(socket)` получает фактический порт,
в том числе при bind с портом 0. `net.udp_close(move socket)` потребляет сокет
один раз даже при ошибке закрытия. Обращение к сокету после move, копирование
или потеря на нормальном выходе запрещены. Это отдельный тип: его нельзя
передать в TCP `net.write` или `net.close_stream`.

`(buffer, result) = net.udp_receive(socket, move buffer)` возвращает владельца
`memory.Buffer<u8>` как при успехе, так и при ошибке. При успехе результат —
`u64` metadata; `net.udp_length`, `net.udp_source_ip` и `net.udp_source_port`
извлекают длину и адрес отправителя. IP — 32-битное значение в порядке октетов,
например 127.0.0.1 = `0x7f000001`. Диапазон `[0, length)` содержит пакет.
Нулевая длина — допустимая датаграмма, а не EOF. Один вызов получает ровно
одну датаграмму, не объединяет пакеты и не повторяет прерванный системный вызов.

`UdpError.Truncated` означает, что входная датаграмма не поместилась: она
поглощена, её префикс может оказаться в буфере и не должен трактоваться как
полный пакет. Содержимое буфера на ошибках не гарантировано; ресурс и региональная
зависимость сохраняются. Вместимость больше 65535 отвергается как `InvalidRange`
до чтения. Пустой буфер допустим. Ошибки I/O возвращаются через `UdpError`.

`net.udp_send(socket, view, start, count, address)` проверяет диапазон
относительно view и отправляет одну датаграмму, в том числе пустую; порт 0 и
диапазон вне view возвращают `InvalidRange`. Вызов не изменяет view и не
создаёт пользовательскую копию payload; сам системный вызов и ОС могут
копировать данные. Успех означает локальное принятие датаграммы, а не доставку.
Сокет и view остаются у вызывающего кода. Размер count ограничен 65535, но ОС
может отклонить размер, превышающий допустимый для конкретного адреса/пути.

Пример `examples/apps/udp_echo.liza` читает и возвращает две датаграммы,
проверяет усечение третьей, затем закрывает сокет и регион. Это минимальный
срез, не готовый сервер: нет неблокирующего UDP reactor, IPv6, DNS, batching,
тайм-аутов, многопоточности или RTP fanout. Потеря, дублирование, перестановка
и перегрузка — свойства UDP/сети, а не гарантии этого API.

```sh
python3 -m unittest discover -s tests -p test_udp.py -v
```

Тест запускает настоящее Liza-приложение при O0/O2, проверяет пустую, полную и
усечённую датаграммы и отрицательные программы владения. Проверки не доказывают
корректность runtime или сетевой ОС на всех входах.
